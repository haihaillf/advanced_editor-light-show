# 灯光秀

一款专业的灯光文件颜色调整工具，支持修改现有灯光文件、创建全新灯光文件、多种预设颜色模式、渐变色效果以及丰富的特效功能。

![关于](关于.png)

## ✨ 功能特性

- 🎨 修改现有灯光文件的颜色
- ✨ 创建全新的灯光文件
- 🌈 12种精心设计的颜色预设
- 🎭 渐变色效果（线性/径向渐变）
- ✨ 丰富的特效（拖尾、闪烁、呼吸、彩虹、波纹、脉冲）
- 👁️ 实时预览
- 📄 多种文件格式支持（RGBW、RGBA、RGB565）

## 🚀 快速开始

### 运行程序

下载最新的 `灯光秀.exe` 并双击运行即可，程序会自动居中显示。

### 界面布局

程序界面分为左右两栏：
- **左侧**：控制面板，包含所有设置选项
- **右侧**：预览面板，实时显示颜色和特效预览

## 📖 使用说明

### 文件操作

#### 选择灯光文件
点击"选择灯光文件"按钮，选择要编辑的 `.bin` 灯光文件。

#### 创建新文件
点击"创建新文件"按钮，打开创建新文件对话框：
- **像素数量**：输入新文件的像素数量（如：10000）
- **快速设置**：点击按钮快速设置常用像素数（1000 / 5000 / 10000 / 50000 / 100000）
- **保存位置**：输入完整的保存路径（如：D:\灯光\new_light.bin）

操作步骤：
1. 设置像素数量
2. 输入保存路径
3. 点击"创建"开始生成
4. 等待进度条完成

### 预设模式

程序提供12种精心设计的颜色预设，点击即可一键应用：

#### 暖色调系列
- 柔和暖光：舒适的温暖光线
- 温馨黄光：温暖的黄色调
- 日落橙光：美丽的日落橙色
- 烛光效果：浪漫的烛光氛围

#### 自然色系
- 自然白光：接近自然光的白色
- 冷白光：清爽的冷白色
- 月光蓝：神秘的月光蓝色
- 森林绿：大自然的绿色

#### 其他颜色
- 浪漫紫：梦幻的紫色
- 节日红：喜庆的红色
- 海洋蓝：深邃的海洋蓝
- 日落金：华贵的金色

### 渐变色设置

#### 启用渐变色
勾选"启用渐变色"复选框，开启渐变效果。

#### 自定义渐变颜色
1. 点击"起始颜色"选择渐变开始的颜色
2. 点击"结束颜色"选择渐变结束的颜色
3. 渐变类型选择：
   - 线性渐变：直线渐变
   - 径向渐变：从中心向外渐变

### 颜色调整

手动微调颜色参数，实现精确控制：
- **红色增强**（范围 0.5 - 2.0）：调整红色分量的强度
- **绿色增强**（范围 0.5 - 2.0）：调整绿色分量的强度
- **蓝色增强**（范围 0.1 - 1.5）：调整蓝色分量的强度

操作提示：
- 拖动滑块即可调整
- 数值实时更新
- 可以随时点击"重置参数"恢复默认值

### 文件格式选择

支持三种常用的灯光文件格式：
- **RGBW**：4字节，红-绿-蓝-白光
- **RGBA**：4字节，红-绿-蓝-透明
- **RGB565**：2字节，高压缩格式

### 特效选择

为灯光添加炫酷的动态效果：

#### 特效列表
- 无特效：不添加任何特效
- 拖尾特效：像素点产生拖尾效果
- 闪烁特效：灯光快速闪烁
- 呼吸特效：灯光缓慢明暗变化
- 彩虹渐变：色彩循环变化
- 波纹特效：像水面波纹一样
- 脉冲特效：像心跳一样脉冲

#### 特效参数设置

**拖尾特效参数**
- 拖尾长度：设置拖尾的长度（1-50）
- 衰减强度：设置拖尾的衰减速度（0.1-1.0）

**闪烁特效参数**
- 闪烁速度：设置闪烁的速度（100-2000毫秒）

**呼吸特效参数**
- 呼吸速度：设置呼吸的速度（500-5000毫秒）

**彩虹特效参数**
- 彩虹速度：设置色彩变化的速度（20-200毫秒）

**波纹特效参数**
- 波纹波速：设置波纹传播的速度（0.1-2.0）

**脉冲特效参数**
- 脉冲速度：设置脉冲的速度（200-3000毫秒）

### 文件转换

#### 开始转换
1. 确保已选择灯光文件或创建新文件
2. 设置好颜色、渐变和特效
3. 点击"开始转换"按钮

#### 取消转换
转换过程中可以点击"取消转换"按钮中断。

#### 转换进度
- 查看进度条了解转换进度
- 查看百分比数值
- 查看操作日志了解详细信息

#### 转换完成
转换完成后，会弹出成功提示，新文件保存在：
- 修改旧文件：原文件同目录，文件名自动添加后缀
- 创建新文件：你设置的保存位置

## ❓ 常见问题

### Q: 程序无法打开怎么办？
A: 确保已下载完整的exe文件，如被杀毒软件拦截，请添加信任。

### Q: 转换后颜色不对怎么办？
A: 检查文件格式选择是否正确，尝试调整RGB参数。

### Q: 特效在预览中可以看到，但转换后没有效果？
A: 确保已正确选择特效并设置了参数，重新尝试转换。

### Q: 创建新文件时选择文件夹无法保存？
A: 请输入完整的文件名路径，如：`D:\灯光\new_light.bin`。
